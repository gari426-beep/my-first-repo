# Caesar Cipher

## Description
A Python program that encrypts messages using the Caesar Cipher technique. Each letter is shifted by a user-defined number of positions in the alphabet.

## Features
- Encrypts text
- User chooses the shift value
- Supports uppercase and lowercase letters
- Keeps spaces and symbols unchanged

## Technologies Used
- Python 3

## How to Run

```bash
py caesar_cipher.py
```

## Example

Input:

Message: HELLO
Shift: 3

Output:

KHOOR

## Learning Outcomes

- Functions in Python
- String manipulation
- ASCII values using ord() and chr()
- Loops and conditions
- Basic cryptography concepts
