# Log Analyzer

## Description
A Python program that analyzes a log file and counts successful and failed login attempts.

## Features
- Reads log files
- Counts successful logins
- Counts failed logins
- Simple and beginner-friendly

## Technologies Used
- Python
- File Handling

## Sample Output

=== Log Analyzer ===
Total log entries: 6
Successful logins: 3
Failed logins: 3
