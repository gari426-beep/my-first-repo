# File Integrity Checker

## Description
A simple Python program that calculates the SHA-256 hash of a file. It can be used to verify whether a file has been modified by comparing its hash value.

## Features
- Calculates SHA-256 hash
- Checks file integrity
- Handles missing files gracefully
- Beginner-friendly Python project

## Technologies Used
- Python 3
- hashlib

## How to Run

1. Clone the repository.

2. Open the project folder.

3. Run the program:

```bash
python file_integrity_checker.py
```

4. Enter the file name or full file path when prompted.
