# 🌐 URL Status Checker

## 📌 Description

A Python tool that checks whether a website is reachable and displays its HTTP status code.

## 🚀 Features

- Checks website availability
- Displays HTTP status codes
- Handles invalid URLs gracefully
- Simple command-line interface

## 🛠 Technologies Used

- Python 3
- Requests Library

## ▶️ How to Run

```bash
py url_status_checker.py
```

Enter a URL including `https://`.

Example:

```
https://www.google.com
```
