# Packet Sniffer

## Description
A simple Python packet sniffer built using Scapy. It captures live network packets and displays protocol information.

## Features
- Captures live packets
- Displays Ethernet, IP and TCP layers
- Shows packet summary
- Beginner-friendly project

## Technologies
- Python
- Scapy
- Npcap (Windows)

## How to Run

pip install scapy

python packet_sniffer.py
