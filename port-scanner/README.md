# Port Scanner

## Overview
This is a simple Python Port Scanner that checks whether common network ports on a target host are open or closed.

## Features
- Scans common TCP ports
- Displays whether each port is open or closed
- Uses Python's built-in `socket` library
- Beginner-friendly implementation

## Technologies Used
- Python
- Socket Library

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/my-first-repo.git
   ```

2. Navigate to the project folder:
   ```bash
   cd port-scanner
   ```

3. Run the program:
   ```bash
   python port_scanner.py
   ```
