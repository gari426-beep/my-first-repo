# 🌐 WHOIS Lookup Tool

## 📌 Description

A Python tool that retrieves WHOIS information for a domain, including its registrar, creation date, expiration date, and name servers.

## 🚀 Features

- Domain WHOIS lookup
- Registrar information
- Creation and expiration dates
- Name server information
- Simple command-line interface

## 🛠 Technologies Used

- Python 3
- python-whois library

## ▶️ How to Run

```bash
py whois_lookup.py
```

Enter a domain name, for example:

```
google.com
```
