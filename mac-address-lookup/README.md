# 🛰️ MAC Address Lookup Tool

## 📌 Description

A Python tool that identifies the vendor/manufacturer of a MAC address using a public API.

## 🚀 Features

- Vendor lookup
- Uses REST API
- Handles invalid MAC addresses
- Beginner-friendly

## 🛠 Technologies Used

- Python 3
- Requests Library
- REST API

## ▶️ How to Run

```bash
py mac_lookup.py
```

Enter a MAC address like:

```
44:38:39:ff:ef:57
```
