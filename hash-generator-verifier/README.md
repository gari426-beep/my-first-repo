# 🔑 Hash Generator & Verifier

## 📌 Description

A Python tool that generates MD5, SHA-1, and SHA-256 hashes for text and verifies SHA-256 hashes.

## 🚀 Features

- Generate MD5 hash
- Generate SHA-1 hash
- Generate SHA-256 hash
- Verify SHA-256 hash
- Beginner-friendly

## 🛠 Technologies Used

- Python 3
- hashlib

## ▶️ How to Run

```bash
py hash_generator.py
```

Enter any text when prompted.
