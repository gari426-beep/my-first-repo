# Network Scanner

## Description

A simple Python program that resolves a hostname into its IP address using Python's socket module.

## Features

- Accepts hostname or IP address
- Resolves hostname to IP
- Handles invalid hostnames
- Easy command-line interface

## Technologies Used

- Python 3
- Socket Module

## Project Structure

```
network-scanner/
│── network_scanner.py
└── README.md
```

## How to Run

```bash
py network_scanner.py
```

## Example

Input:

```
google.com
```

Output:

```
Host Information
----------------
Hostname : google.com
IP Address: 142.xxx.xxx.xxx
```
