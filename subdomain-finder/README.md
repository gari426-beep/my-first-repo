# 🔍 Subdomain Finder

## 📌 Description
This Python project discovers subdomains of a target domain using DNS resolution. It reads a list of common subdomains from a text file and checks whether they exist.

## 🚀 Features
- Finds common subdomains
- Uses DNS lookups
- Reads subdomains from a text file
- Displays discovered subdomains with their IP addresses
- Simple and beginner-friendly

## 🛠 Technologies Used
- Python 3
- Socket Module
- File Handling

## ▶️ How to Run

```bash
py subdomain_finder.py
```

Enter a domain such as:

```
google.com
```
