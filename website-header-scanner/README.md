# Website Header Scanner

## Description

A Python tool that retrieves and displays HTTP response headers from any website.

## Features

- Fetches website response headers
- Displays security-related headers
- Handles connection errors
- Simple command-line interface

## Technologies Used

- Python 3
- Requests Library

## Project Structure

```
website-header-scanner/
│── website_header_scanner.py
└── README.md
```

## How to Run

```bash
py website_header_scanner.py
```

## Example

Input:

```
https://google.com
```

Output:

```
Server: gws
Content-Type: text/html
X-Frame-Options: SAMEORIGIN
```
