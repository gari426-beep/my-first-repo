# 🌍 IP Geolocation Tool

## 📌 Description
A Python tool that retrieves geographical information about an IP address using a public API.

## 🚀 Features
- Finds country
- Finds region/state
- Finds city
- Displays ISP
- Shows latitude and longitude
- Displays timezone

## 🛠 Technologies Used
- Python 3
- Requests Library
- REST API
- JSON

## ▶️ How to Run

```bash
py ip_geolocation.py
```

Enter an IP address, for example:

```
8.8.8.8
```
