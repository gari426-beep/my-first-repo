# 🔐 Password Leak Checker

## 📌 Description

A Python tool that checks whether a password has appeared in known data breaches using the Have I Been Pwned Passwords API.

> The password itself is never sent to the API. The project uses the k-anonymity model for privacy.

---

## 🚀 Features

- Generates SHA-1 hash
- Uses the Have I Been Pwned Passwords API
- Privacy-friendly password checking
- Displays breach count
- Handles network errors gracefully

---

## 🛠 Technologies Used

- Python 3
- hashlib
- requests

---

## ▶️ How to Run

```bash
py password_leak_checker.py
```

Enter a password when prompted.
