# 📂 Directory Brute Forcer

A simple Python tool that scans a website for common directories using a custom wordlist.

> ⚠️ This project is for educational purposes only. Only scan websites that you own or have permission to test.

---

## 🚀 Features

- Scan websites for common directories
- Uses a custom wordlist
- Detects accessible directories (HTTP 200)
- Detects forbidden directories (HTTP 403)
- Handles connection errors gracefully

---

## 🛠 Technologies Used

- Python 3
- Requests Library

---

## 📂 Project Structure

directory-brute-forcer/

## ▶️ How to Run

Install the Requests library:

```bash
pip install requests
```

Run the program:

```bash
python directory_bruteforcer.py
```

Enter a website URL when prompted:

```
https://example.com
```
